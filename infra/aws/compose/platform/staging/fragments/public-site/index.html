Le projet Fragments

Un café.
Un lieu.
Un souvenir.

Certains cafés deviennent des habitudes. D’autres restent le souvenir d’une rencontre, d’une rue ou d’un moment à soi. Fragments part de cette idée : un lieu mérite parfois plus qu’une adresse enregistrée.

Pourquoi Fragments ?

Relier les lieux
aux moments.

Fragments rapproche la découverte d’un café et l’expérience qu’on en garde. L’envie est simple : donner envie de pousser une nouvelle porte, retrouver ses adresses et raconter une visite avec ses propres mots.

01 / Découvrir

Trouver une adresse

Explorer la carte, consulter les informations d’un café, retrouver ses favoris et lire des articles pour prolonger la découverte.

02 / Vivre

Prendre le temps

Le point de départ reste une vraie visite. Un café de quartier, une halte en voyage ou une adresse à laquelle on revient.

03 / Partager

En garder un fragment

Partager une expérience avec du texte, une photo, ou les deux. Une trace personnelle plutôt qu’une note à attribuer au lieu.

Expériences & Pass

Une visite se raconte.
Une preuve se distingue.

On peut partager une expérience avec ou sans ticket. Le ticket n’est pas un droit d’entrée dans la conversation.

Le Pass accompagne le parcours dans Fragments. Certains niveaux demandent des visites vérifiées : dans ce cas, un ticket permet de distinguer une preuve de visite d’un simple récit. Les règles de progression restent celles affichées dans l’application.

Application iPhone en phase de test

Un projet qui
se construit sur le terrain.

Fragments est en préparation pour une première publication. La version actuelle est testée sur iPhone afin de vérifier les parcours de découverte, les expériences, les photos, le compte et les usages hors ligne.

La priorité est de rendre ces usages fiables, tout en gardant une interface simple et une place centrale pour les lieux. L’application n’est pas encore disponible publiquement sur l’App Store.
