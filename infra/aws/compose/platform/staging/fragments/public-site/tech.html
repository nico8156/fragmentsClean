À part, pour les curieux

LA TECH.

Une application mobile qui reste utilisable quand le réseau hésite, et un serveur qui garde la vérité des données.

01 / Mobile

Une interface qui n’attend pas.

Fragments est construit avec React Native et Expo. Les actions importantes sont conservées localement lorsqu’une connexion échoue, puis réconciliées avec le serveur. Une panne réseau n’est pas confondue avec un refus métier.

02 / Serveur

Des frontières métier claires.

Le backend Spring Boot est un monolithe modulaire. Cafés, articles, comptes, tickets et expériences ont chacun leurs responsabilités. PostgreSQL conserve les données et les modèles de lecture.

03 / Échanges

Des faits, pas des suppositions.

Les commandes expriment une intention ; les événements décrivent ce qui s’est produit. Une outbox transactionnelle et des consommateurs idempotents sécurisent les traitements asynchrones. La synchronisation SSE indique au mobile quand recharger ses données ; le statut d’une commande reste consultable auprès du serveur.

04 / Exploitation

Construire pour durer.

AWS héberge l’environnement de test, avec SQS pour les messages et S3 pour les objets. Les parcours critiques sont vérifiés par des tests métier, d’intégration et de contrats. Ces choix n’affirment pas qu’aucune panne ne peut survenir : ils rendent les erreurs plus faciles à reprendre et à diagnostiquer.
